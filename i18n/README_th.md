## AI Gateway & Router

- [axonhub](https://github.com/looplj/axonhub) — AI Gateway แบบโอเพนซอร์ส: เรียกใช้ LLM กว่า 100 ตัวผ่าน SDK ใดก็ได้ พร้อมระบบ failover, การกระจายโหลด และการติดตามในตัว

## เฟรมเวิร์กและฮาร์เนสสำหรับ Agent

- [oumi](https://github.com/oumi-ai/oumi) — ปรับแต่ง (fine-tune) ประเมินผล และนำไปใช้งานกับ Gemma, Qwen, gpt-oss, DeepSeek-R1 และ LLM / VLM โอเพนซอร์สอื่น ๆ
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — เทมเพลต FastAPI พร้อมใช้งานจริงสำหรับสร้างบริการ AI agent ด้วย LangGraph
- [octos](https://github.com/octos-org/octos) — ระบบปฏิบัติการแบบ Agentic
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — ฮาร์เนส agent ที่รวดเร็วและใช้งานง่าย สำหรับระบบ AI แบบหลายโมเดล หลายเครื่องมือ และทำงานระยะยาว
- [stash](https://github.com/alash3al/stash) — ชั้นหน่วยความจำถาวรสำหรับ AI agent รองรับด้วย Postgres พร้อม MCP server ในตัว

## Coding Agents

- [reopencode](https://github.com/MurrayHill1127/reopencode) — AI coding agent แบบโอเพนซอร์ส
- [VTCode](https://github.com/vinhnx/VTCode) — Coding agent ที่เข้าใจโค้ดในระดับ LLM-native พร้อมความปลอดภัยของ shell ที่แข็งแกร่ง
- [mathcode](https://github.com/math-ai-org/mathcode) — Coding agent ด้านคณิตศาสตร์ระดับแนวหน้า

## RAG & Data Pipelines

- [Verba](https://github.com/weaviate/Verba) — แชตบอต Retrieval-Augmented Generation (RAG) ขับเคลื่อนด้วย Weaviate
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — Crawler ที่แปลงเว็บไซต์ให้เป็นข้อมูลพร้อมใช้กับ LLM และผลลัพธ์ SERP แบบมีโครงสร้าง

## LLM Frameworks

- [LLPhant](https://github.com/LLPhant/LLPhant) — เฟรมเวิร์ก Generative AI สำหรับ PHP ที่ครบครัน ได้แรงบันดาลใจจาก LangChain

## ภาพ วิดีโอ และมัลติโมดัล

- [LightX2V](https://github.com/ModelTC/LightX2V) — เฟรมเวิร์ก inference สำหรับการสร้างภาพ / วิดีโอที่มีน้ำหนักเบา
- [paperbanana](https://github.com/llmsresearch/paperbanana) — สร้างภาพประกอบเชิงวิชาการ ไดอะแกรม และภาพงานวิจัยโดยอัตโนมัติ
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — เครื่องมือแปลมังงะแบบโอเพนซอร์ส พร้อมตัวแก้ไขแบบภาพและรองรับหลายเอนจิน
- [opentalking](https://github.com/datascale-ai/opentalking) — เฟรมเวิร์กมนุษย์ดิจิทัล AI ระดับอุตสาหกรรม พร้อมการสนทนาแบบเรียลไทม์
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — MCP และ skill สำหรับวาดภาพ ใช้ได้ใน OpenClaw หรือ agent ใด ๆ ที่รองรับ MCP
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — โรงงาน AIGC ส่วนตัวของคุณเอง ในสไตล์ Comfy

## การทดสอบและความปลอดภัย

- [promptfoo](https://github.com/promptfoo/promptfoo) — ทดสอบ prompt, agent และ RAG; ทำ red teaming และสแกนช่องโหว่สำหรับ AI
- [gosec](https://github.com/securego/gosec) — เครื่องตรวจสอบความปลอดภัยสำหรับ Go

## เบราว์เซอร์และเครื่องมือเว็บ

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — ไดอะแกรมแบบโต้ตอบที่รวดเร็วและฟรีสำหรับ GitHub repository ใด ๆ
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — อีกหนึ่ง WebUI สำหรับ Nginx
- [page-assist](https://github.com/n4ze3m/page-assist) — ใช้โมเดล AI ที่รันในเครื่องของคุณช่วยในการท่องเว็บ
- [design-extract](https://github.com/Manavarya09/design-extract) — สกัด design system ทั้งหมดของเว็บไซต์ใด ๆ ด้วยคำสั่งเดียว

## แอปเดสก์ท็อปและแอปคู่หู

- [hermes-desktop](https://github.com/fathah/hermes-desktop) — แอปคู่หูบนเดสก์ท็อปสำหรับ Hermes Agent
- [fount](https://github.com/steve02081504/fount) — มอบเสียงให้กับจินตนาการ — แพลตฟอร์มตัวละคร / เพื่อนคู่หู

## การเรียนรู้และทักษะ

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) — แปลงเว็บไซต์เอกสาร, GitHub repo และ PDF ให้เป็น skill ของ Claude AI
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) — สมุดบันทึก (notebook) ที่ช่วยให้คุณเรียนรู้ AI ตั้งแต่เริ่มต้น

## เกี่ยวกับ Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) คือแพลตฟอร์ม AI inference แบบครบทุกโมดัล — API และ endpoint เดียวที่เข้ากันได้กับ OpenAI (`https://api.atlascloud.ai/v1`) สำหรับโมเดลคัดสรรกว่า 300 ตัว:

- **LLM** — DeepSeek, Qwen, Claude, GPT, Gemini, GLM, Kimi, MiniMax, Grok และอื่น ๆ
- **ภาพ** — FLUX, Seedream, gpt-image และอื่น ๆ
- **วิดีโอ** — Seedance, Kling, Wan และอื่น ๆ
