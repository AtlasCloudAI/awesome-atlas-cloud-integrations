## AI Gateway & Router

- [axonhub](https://github.com/looplj/axonhub) — AI Gateway open-source: panggil 100+ LLM melalui SDK apa pun, dengan failover, load balancing, dan tracing bawaan.

## Framework & Harness untuk Agent

- [oumi](https://github.com/oumi-ai/oumi) — Fine-tune, evaluasi, dan deploy Gemma, Qwen, gpt-oss, DeepSeek-R1, dan LLM / VLM open lainnya.
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — Template FastAPI siap produksi untuk membangun layanan AI agent dengan LangGraph.
- [octos](https://github.com/octos-org/octos) — Sistem Operasi Agentic.
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — Harness agent yang cepat dan mudah digunakan untuk sistem AI berjangka panjang, multi-model, dan berbasis tool.
- [stash](https://github.com/alash3al/stash) — Lapisan memori persisten untuk AI agent, didukung oleh Postgres, dengan MCP server bawaan.

## Coding Agents

- [reopencode](https://github.com/MurrayHill1127/reopencode) — AI coding agent open-source.
- [VTCode](https://github.com/vinhnx/VTCode) — Coding agent dengan pemahaman kode LLM-native dan keamanan shell yang andal.
- [mathcode](https://github.com/math-ai-org/mathcode) — Coding agent matematika terdepan.

## RAG & Data Pipelines

- [Verba](https://github.com/weaviate/Verba) — Chatbot Retrieval-Augmented Generation (RAG) yang ditenagai Weaviate.
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — Crawler yang mengubah situs web menjadi data siap-LLM dan hasil SERP terstruktur.

## LLM Frameworks

- [LLPhant](https://github.com/LLPhant/LLPhant) — Framework Generative AI PHP yang komprehensif, terinspirasi dari LangChain.

## Gambar, Video & Multimodal

- [LightX2V](https://github.com/ModelTC/LightX2V) — Framework inference pembuatan gambar / video yang ringan.
- [paperbanana](https://github.com/llmsresearch/paperbanana) — Figur akademik, diagram, dan visual penelitian secara otomatis.
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — Tool penerjemahan manga open-source dengan editor visual dan beragam engine.
- [opentalking](https://github.com/datascale-ai/opentalking) — Framework manusia digital AI kelas industri dengan percakapan real-time.
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — MCP & skill menggambar yang dapat digunakan di OpenClaw atau agent apa pun yang mendukung MCP.
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — Pabrik AIGC pribadi Anda sendiri, dengan cara Comfy.

## Pengujian & Keamanan

- [promptfoo](https://github.com/promptfoo/promptfoo) — Uji prompt, agent, dan RAG; red teaming dan pemindaian kerentanan untuk AI.
- [gosec](https://github.com/securego/gosec) — Pemeriksa keamanan Go.

## Browser & Tool Web

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — Diagram interaktif gratis dan cepat untuk GitHub repository mana pun.
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — Satu lagi WebUI untuk Nginx.
- [page-assist](https://github.com/n4ze3m/page-assist) — Gunakan model AI yang berjalan lokal untuk membantu penelusuran web Anda.
- [design-extract](https://github.com/Manavarya09/design-extract) — Ekstrak seluruh design system situs web mana pun dengan satu perintah.

## Aplikasi Desktop & Pendamping

- [hermes-desktop](https://github.com/fathah/hermes-desktop) — Aplikasi pendamping desktop untuk Hermes Agent.
- [fount](https://github.com/steve02081504/fount) — Imajinasi yang diberi suara — platform karakter / pendamping.

## Pembelajaran & Skill

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) — Ubah situs dokumentasi, GitHub repo, dan PDF menjadi skill Claude AI.
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) — Notebook untuk membantu Anda belajar AI dari awal.

## Berkontribusi

Kontribusi sangat diterima! Buka PR untuk menambahkan proyek open-source yang mengintegrasikan Atlas Cloud (LLM / gambar / video) sebagai penyedia AI. Jaga formatnya tetap sederhana:

```md
- [name](repo-url) — One-line description.
```

Tambahkan entri di bawah kategori yang paling relevan. Lihat [CONTRIBUTING.md](../CONTRIBUTING.md).

## Tentang Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) adalah platform AI inference full-modal — satu API dan endpoint yang kompatibel dengan OpenAI (`https://api.atlascloud.ai/v1`) untuk 300+ model pilihan:

- **LLM** — DeepSeek, Qwen, Claude, GPT, Gemini, GLM, Kimi, MiniMax, Grok, dan lainnya
- **Gambar** — FLUX, Seedream, gpt-image, dan lainnya
- **Video** — Seedance, Kling, Wan, dan lainnya
