## AI Gateway & Router

- [axonhub](https://github.com/looplj/axonhub) — Otwartoźródłowy AI Gateway: wywołuj ponad 100 LLM przez dowolne SDK, z wbudowanym przełączaniem awaryjnym, równoważeniem obciążenia i śledzeniem.

## Frameworki i harnessy agentów

- [oumi](https://github.com/oumi-ai/oumi) — Dostrajaj, oceniaj i wdrażaj Gemma, Qwen, gpt-oss, DeepSeek-R1 oraz inne otwarte LLM / VLM.
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — Gotowy do produkcji szablon FastAPI do budowania usług agentów AI z LangGraph.
- [octos](https://github.com/octos-org/octos) — Agentowy system operacyjny.
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — Szybki, łatwy w użyciu harness agenta dla systemów AI o długim horyzoncie, wielomodelowych i korzystających z narzędzi.
- [stash](https://github.com/alash3al/stash) — Trwała warstwa pamięci dla agentów AI, oparta na Postgres, z wbudowanym serwerem MCP.

## Agenci do kodowania

- [reopencode](https://github.com/MurrayHill1127/reopencode) — Otwartoźródłowy agent AI do kodowania.
- [VTCode](https://github.com/vinhnx/VTCode) — Agent do kodowania z natywnym dla LLM rozumieniem kodu i solidnym bezpieczeństwem powłoki.
- [mathcode](https://github.com/math-ai-org/mathcode) — Zaawansowany matematyczny agent do kodowania.

## RAG i potoki danych

- [Verba](https://github.com/weaviate/Verba) — Chatbot Retrieval-Augmented Generation (RAG) napędzany przez Weaviate.
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — Crawler, który zamienia strony internetowe w dane gotowe dla LLM oraz ustrukturyzowane wyniki SERP.

## Frameworki LLM

- [LLPhant](https://github.com/LLPhant/LLPhant) — Kompleksowy framework PHP do generatywnej AI, inspirowany LangChain.

## Obraz, wideo i multimodalność

- [LightX2V](https://github.com/ModelTC/LightX2V) — Lekki framework inferencyjny do generowania obrazów / wideo.
- [paperbanana](https://github.com/llmsresearch/paperbanana) — Zautomatyzowane akademickie ryciny, diagramy i wizualizacje badawcze.
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — Otwartoźródłowe narzędzie do tłumaczenia mangi z edytorem wizualnym i wieloma silnikami.
- [opentalking](https://github.com/datascale-ai/opentalking) — Przemysłowy framework AI dla cyfrowych ludzi z konwersacją w czasie rzeczywistym.
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — MCP i skill do rysowania, używalny w OpenClaw lub dowolnym agencie obsługującym MCP.
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — Twoja własna osobista fabryka AIGC, w stylu Comfy.

## Testowanie i bezpieczeństwo

- [promptfoo](https://github.com/promptfoo/promptfoo) — Testuj prompty, agentów i RAG-i; red teaming i skanowanie podatności dla AI.
- [gosec](https://github.com/securego/gosec) — Kontroler bezpieczeństwa dla Go.

## Narzędzia przeglądarkowe i webowe

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — Darmowe, szybkie interaktywne diagramy dla dowolnego repozytorium GitHub.
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — Kolejny WebUI dla Nginx.
- [page-assist](https://github.com/n4ze3m/page-assist) — Wykorzystaj lokalnie działające modele AI, aby wspomóc przeglądanie sieci.
- [design-extract](https://github.com/Manavarya09/design-extract) — Wyodrębnij kompletny system projektowy dowolnej strony internetowej jednym poleceniem.

## Aplikacje desktopowe i towarzyszące

- [hermes-desktop](https://github.com/fathah/hermes-desktop) — Desktopowy towarzysz dla Hermes Agent.
- [fount](https://github.com/steve02081504/fount) — Wyobraźnia, której nadano głos — platforma postaci / towarzyszy.

## Nauka i skille

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) — Przekształcaj witryny z dokumentacją, repozytoria GitHub i pliki PDF w skille Claude AI.
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) — Notatniki pomagające uczyć się AI od podstaw.

Dodaj wpis w najbardziej odpowiedniej kategorii. Zobacz [CONTRIBUTING.md](../CONTRIBUTING.md).

## O Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) to w pełni multimodalna platforma inferencji AI — jedno OpenAI-compatible API i punkt końcowy (`https://api.atlascloud.ai/v1`) dla ponad 300 wyselekcjonowanych modeli:

- **LLM** — DeepSeek, Qwen, Claude, GPT, Gemini, GLM, Kimi, MiniMax, Grok i więcej
- **Obraz** — FLUX, Seedream, gpt-image i więcej
- **Wideo** — Seedance, Kling, Wan i więcej
