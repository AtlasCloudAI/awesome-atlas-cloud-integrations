## AI 网关与路由

- [axonhub](https://github.com/looplj/axonhub) — 开源 AI 网关：通过任意 SDK 调用 100+ 个 LLM，内置故障转移、负载均衡与链路追踪。

## Agent 框架与运行环境

- [oumi](https://github.com/oumi-ai/oumi) — 微调、评估并部署 Gemma、Qwen、gpt-oss、DeepSeek-R1 等开源 LLM / VLM。
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — 用 LangGraph 构建 AI agent 服务的生产级 FastAPI 模板。
- [octos](https://github.com/octos-org/octos) — Agentic 操作系统。
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — 面向长程、多模型、可调用工具的 AI 系统的快速易用 agent 运行环境。
- [stash](https://github.com/alash3al/stash) — 面向 AI agent 的持久化记忆层，基于 Postgres，内置 MCP 服务器。

## 编程 Agent

- [reopencode](https://github.com/MurrayHill1127/reopencode) — 开源 AI 编程 agent。
- [VTCode](https://github.com/vinhnx/VTCode) — 具备 LLM 原生代码理解能力与稳健 shell 安全机制的编程 agent。
- [mathcode](https://github.com/math-ai-org/mathcode) — 前沿的数学编程 agent。

## RAG 与数据管线

- [Verba](https://github.com/weaviate/Verba) — 基于 Weaviate 的检索增强生成（RAG）聊天机器人。
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — 将网站转化为 LLM 就绪数据与结构化 SERP 结果的爬虫。

## LLM 框架

- [LLPhant](https://github.com/LLPhant/LLPhant) — 一个全面的 PHP 生成式 AI 框架，灵感来自 LangChain。

## 图像、视频与多模态

- [LightX2V](https://github.com/ModelTC/LightX2V) — 轻量级图像 / 视频生成推理框架。
- [paperbanana](https://github.com/llmsresearch/paperbanana) — 自动生成学术插图、示意图与科研可视化。
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — 带可视化编辑器与多引擎的开源漫画翻译工具。
- [opentalking](https://github.com/datascale-ai/opentalking) — 工业级 AI 数字人框架，支持实时对话。
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — 可在 OpenClaw 或任意支持 MCP 的 agent 中使用的绘图 MCP 与 skill。
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — 属于你自己的私人 AIGC 工厂，Comfy 方式。

## 测试与安全

- [promptfoo](https://github.com/promptfoo/promptfoo) — 测试提示词、agent 与 RAG；面向 AI 的红队演练与漏洞扫描。
- [gosec](https://github.com/securego/gosec) — Go 安全检查工具。

## 浏览器与 Web 工具

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — 为任意 GitHub 仓库免费、快速生成交互式图表。
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — 又一款 Nginx 的 WebUI。
- [page-assist](https://github.com/n4ze3m/page-assist) — 用本地运行的 AI 模型辅助你的网页浏览。
- [design-extract](https://github.com/Manavarya09/design-extract) — 一条命令提取任意网站完整的设计系统。

## 桌面与陪伴应用

- [hermes-desktop](https://github.com/fathah/hermes-desktop) — Hermes Agent 的桌面伴侣应用。
- [fount](https://github.com/steve02081504/fount) — 让想象发声 —— 一个角色 / 陪伴平台。

## 学习与技能

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) — 将文档站点、GitHub 仓库与 PDF 转换为 Claude AI skill。
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) — 帮助你从零开始学习 AI 的 notebook。

## 关于 Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) 是一个全模态 AI 推理平台 —— 一套 OpenAI-compatible API 与端点（`https://api.atlascloud.ai/v1`），精选 300+ 个模型：

- **LLM** — DeepSeek、Qwen、Claude、GPT、Gemini、GLM、Kimi、MiniMax、Grok 等
- **图像** — FLUX、Seedream、gpt-image 等
- **视频** — Seedance、Kling、Wan 等
