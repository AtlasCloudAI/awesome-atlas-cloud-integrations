## AI Gateway y Router

- [axonhub](https://github.com/looplj/axonhub) — AI Gateway de código abierto: llama a más de 100 LLM desde cualquier SDK, con failover, balanceo de carga y trazabilidad integrados.

## Frameworks y entornos de agentes

- [oumi](https://github.com/oumi-ai/oumi) — Ajusta, evalúa y despliega Gemma, Qwen, gpt-oss, DeepSeek-R1 y otros LLM / VLM abiertos.
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — Plantilla FastAPI lista para producción para crear servicios de agentes de IA con LangGraph.
- [octos](https://github.com/octos-org/octos) — Sistema operativo agéntico.
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — Entorno de agentes rápido y fácil de usar para sistemas de IA de largo horizonte, multimodelo y con uso de herramientas.
- [stash](https://github.com/alash3al/stash) — Capa de memoria persistente para agentes de IA, respaldada por Postgres y con un servidor MCP integrado.

## Agentes de programación

- [reopencode](https://github.com/MurrayHill1127/reopencode) — Agente de programación de IA de código abierto.
- [VTCode](https://github.com/vinhnx/VTCode) — Agente de programación con comprensión de código nativa de LLM y robusta seguridad de shell.
- [mathcode](https://github.com/math-ai-org/mathcode) — Un agente de programación matemática de vanguardia.

## RAG y pipelines de datos

- [Verba](https://github.com/weaviate/Verba) — Chatbot de generación aumentada por recuperación (RAG) impulsado por Weaviate.
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — Crawler que convierte sitios web en datos listos para LLM y resultados SERP estructurados.

## Frameworks de LLM

- [LLPhant](https://github.com/LLPhant/LLPhant) — Un framework PHP completo de IA generativa, inspirado en LangChain.

## Imagen, vídeo y multimodal

- [LightX2V](https://github.com/ModelTC/LightX2V) — Framework de inferencia ligero para generación de imágenes / vídeo.
- [paperbanana](https://github.com/llmsresearch/paperbanana) — Figuras académicas, diagramas y material visual de investigación automatizados.
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — Herramienta de traducción de manga de código abierto con editor visual y múltiples motores.
- [opentalking](https://github.com/datascale-ai/opentalking) — Framework de humano digital de IA de nivel industrial con conversación en tiempo real.
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — MCP y skill de dibujo utilizables en OpenClaw o en cualquier agente compatible con MCP.
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — Tu propia fábrica de AIGC personal, al estilo Comfy.

## Pruebas y seguridad

- [promptfoo](https://github.com/promptfoo/promptfoo) — Prueba prompts, agentes y RAG; red teaming y análisis de vulnerabilidades para IA.
- [gosec](https://github.com/securego/gosec) — Verificador de seguridad para Go.

## Navegador y herramientas web

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — Diagramas interactivos gratuitos y rápidos para cualquier repositorio de GitHub.
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — Otra WebUI más para Nginx.
- [page-assist](https://github.com/n4ze3m/page-assist) — Usa tus modelos de IA ejecutándose localmente para asistirte en la navegación web.
- [design-extract](https://github.com/Manavarya09/design-extract) — Extrae el sistema de diseño completo de cualquier sitio web con un solo comando.

## Apps de escritorio y de compañía

- [hermes-desktop](https://github.com/fathah/hermes-desktop) — Aplicación de compañía de escritorio para Hermes Agent.
- [fount](https://github.com/steve02081504/fount) — Imaginación con voz propia: una plataforma de personajes / compañía.

## Aprendizaje y skills

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) — Convierte sitios de documentación, repositorios de GitHub y PDF en skills de Claude AI.
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) — Notebooks para ayudarte a aprender IA desde cero.

## Acerca de Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) es una plataforma de inferencia de IA de modalidad completa: una única API y endpoint compatibles con OpenAI (`https://api.atlascloud.ai/v1`) para más de 300 modelos curados:

- **LLM** — DeepSeek, Qwen, Claude, GPT, Gemini, GLM, Kimi, MiniMax, Grok y más
- **Imagen** — FLUX, Seedream, gpt-image y más
- **Vídeo** — Seedance, Kling, Wan y más
