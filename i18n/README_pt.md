## AI Gateway e Router

- [axonhub](https://github.com/looplj/axonhub) — AI Gateway de código aberto: chame mais de 100 LLMs por meio de qualquer SDK, com failover, balanceamento de carga e rastreamento integrados.

## Frameworks e ambientes de agentes

- [oumi](https://github.com/oumi-ai/oumi) — Faça fine-tuning, avalie e implante Gemma, Qwen, gpt-oss, DeepSeek-R1 e outros LLMs / VLMs abertos.
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — Modelo FastAPI pronto para produção para criar serviços de agentes de IA com LangGraph.
- [octos](https://github.com/octos-org/octos) — Sistema operacional agêntico.
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — Ambiente de agentes rápido e fácil de usar para sistemas de IA de longo horizonte, multimodelo e que usam ferramentas.
- [stash](https://github.com/alash3al/stash) — Camada de memória persistente para agentes de IA, baseada em Postgres, com servidor MCP integrado.

## Agentes de programação

- [reopencode](https://github.com/MurrayHill1127/reopencode) — Agente de programação de IA de código aberto.
- [VTCode](https://github.com/vinhnx/VTCode) — Agente de programação com compreensão de código nativa de LLM e segurança de shell robusta.
- [mathcode](https://github.com/math-ai-org/mathcode) — Um agente de programação matemática de ponta.

## RAG e pipelines de dados

- [Verba](https://github.com/weaviate/Verba) — Chatbot de geração aumentada por recuperação (RAG) alimentado pelo Weaviate.
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — Crawler que transforma sites em dados prontos para LLM e resultados SERP estruturados.

## Frameworks de LLM

- [LLPhant](https://github.com/LLPhant/LLPhant) — Um framework PHP completo de IA generativa, inspirado no LangChain.

## Imagem, vídeo e multimodal

- [LightX2V](https://github.com/ModelTC/LightX2V) — Framework de inferência leve para geração de imagens / vídeo.
- [paperbanana](https://github.com/llmsresearch/paperbanana) — Figuras acadêmicas, diagramas e recursos visuais de pesquisa automatizados.
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — Ferramenta de tradução de mangá de código aberto com editor visual e múltiplos motores.
- [opentalking](https://github.com/datascale-ai/opentalking) — Framework de humano digital de IA de nível industrial com conversa em tempo real.
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — MCP e skill de desenho utilizáveis no OpenClaw ou em qualquer agente compatível com MCP.
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — Sua própria fábrica pessoal de AIGC, ao estilo Comfy.

## Testes e segurança

- [promptfoo](https://github.com/promptfoo/promptfoo) — Teste prompts, agentes e RAGs; red teaming e varredura de vulnerabilidades para IA.
- [gosec](https://github.com/securego/gosec) — Verificador de segurança para Go.

## Navegador e ferramentas web

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — Diagramas interativos gratuitos e rápidos para qualquer repositório do GitHub.
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — Mais uma WebUI para o Nginx.
- [page-assist](https://github.com/n4ze3m/page-assist) — Use seus modelos de IA em execução local para auxiliar sua navegação na web.
- [design-extract](https://github.com/Manavarya09/design-extract) — Extraia o sistema de design completo de qualquer site com um único comando.

## Apps de desktop e de companhia

- [hermes-desktop](https://github.com/fathah/hermes-desktop) — Aplicativo de companhia para desktop do Hermes Agent.
- [fount](https://github.com/steve02081504/fount) — Imaginação com voz própria: uma plataforma de personagens / companhia.

## Aprendizado e skills

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) — Converta sites de documentação, repositórios do GitHub e PDFs em skills do Claude AI.
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) — Notebooks para ajudar você a aprender IA do zero.

## Contributing

Contribuições são bem-vindas! Abra um PR para adicionar um projeto de código aberto que integre o Atlas Cloud (LLM / imagem / vídeo) como provedor de IA. Mantenha o formato simples:

```md
- [name](repo-url) — One-line description.
```

Adicione a entrada na categoria mais relevante. Veja [CONTRIBUTING.md](../CONTRIBUTING.md).

## Sobre o Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) é uma plataforma de inferência de IA de modalidade completa: uma única API e endpoint compatíveis com OpenAI (`https://api.atlascloud.ai/v1`) para mais de 300 modelos curados:

- **LLMs** — DeepSeek, Qwen, Claude, GPT, Gemini, GLM, Kimi, MiniMax, Grok e mais
- **Imagem** — FLUX, Seedream, gpt-image e mais
- **Vídeo** — Seedance, Kling, Wan e mais

[Site](https://www.atlascloud.ai) · [Documentação](https://www.atlascloud.ai/docs) · [Modelos](https://www.atlascloud.ai/models) · [Coding Plan](https://www.atlascloud.ai/console/coding-plan)
