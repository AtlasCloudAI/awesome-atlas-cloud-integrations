## AI Gateway & Router

- [axonhub](https://github.com/looplj/axonhub) — AI Gateway mã nguồn mở: gọi hơn 100 LLM qua bất kỳ SDK nào, tích hợp sẵn failover, cân bằng tải và tracing.

## Khung và Harness cho Agent

- [oumi](https://github.com/oumi-ai/oumi) — Tinh chỉnh (fine-tune), đánh giá và triển khai Gemma, Qwen, gpt-oss, DeepSeek-R1 cùng các LLM / VLM mã nguồn mở khác.
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — Mẫu FastAPI sẵn sàng cho môi trường production để xây dựng dịch vụ AI agent với LangGraph.
- [octos](https://github.com/octos-org/octos) — Hệ điều hành theo hướng Agentic.
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — Harness agent nhanh, dễ dùng cho các hệ thống AI dài hạn, đa mô hình và sử dụng công cụ.
- [stash](https://github.com/alash3al/stash) — Lớp bộ nhớ bền vững cho AI agent, dựa trên Postgres, kèm MCP server tích hợp sẵn.

## Coding Agents

- [reopencode](https://github.com/MurrayHill1127/reopencode) — AI coding agent mã nguồn mở.
- [VTCode](https://github.com/vinhnx/VTCode) — Coding agent với khả năng hiểu mã LLM-native và an toàn shell mạnh mẽ.
- [mathcode](https://github.com/math-ai-org/mathcode) — Một coding agent toán học tiên tiến.

## RAG & Data Pipelines

- [Verba](https://github.com/weaviate/Verba) — Chatbot Retrieval-Augmented Generation (RAG) chạy bằng Weaviate.
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — Trình thu thập dữ liệu biến website thành dữ liệu sẵn sàng cho LLM và kết quả SERP có cấu trúc.

## LLM Frameworks

- [LLPhant](https://github.com/LLPhant/LLPhant) — Một khung Generative AI toàn diện cho PHP, lấy cảm hứng từ LangChain.

## Ảnh, Video & Đa phương thức

- [LightX2V](https://github.com/ModelTC/LightX2V) — Khung inference tạo ảnh / video nhẹ.
- [paperbanana](https://github.com/llmsresearch/paperbanana) — Tự động tạo hình minh họa học thuật, sơ đồ và hình ảnh nghiên cứu.
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — Công cụ dịch manga mã nguồn mở với trình chỉnh sửa trực quan và nhiều engine.
- [opentalking](https://github.com/datascale-ai/opentalking) — Khung người kỹ thuật số AI cấp công nghiệp với hội thoại thời gian thực.
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — MCP và skill vẽ tranh dùng được trong OpenClaw hoặc bất kỳ agent nào hỗ trợ MCP.
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — Nhà máy AIGC cá nhân của riêng bạn, theo phong cách Comfy.

## Kiểm thử & Bảo mật

- [promptfoo](https://github.com/promptfoo/promptfoo) — Kiểm thử prompt, agent và RAG; red teaming và quét lỗ hổng cho AI.
- [gosec](https://github.com/securego/gosec) — Trình kiểm tra bảo mật cho Go.

## Trình duyệt & Công cụ Web

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — Sơ đồ tương tác miễn phí, nhanh chóng cho bất kỳ GitHub repository nào.
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — Một WebUI nữa cho Nginx.
- [page-assist](https://github.com/n4ze3m/page-assist) — Dùng các mô hình AI chạy cục bộ để hỗ trợ duyệt web.
- [design-extract](https://github.com/Manavarya09/design-extract) — Trích xuất toàn bộ design system của bất kỳ website nào chỉ với một lệnh.

## Ứng dụng Desktop & Đồng hành

- [fount](https://github.com/steve02081504/fount) — Trí tưởng tượng được cất tiếng nói — một nền tảng nhân vật / người đồng hành.

## Về Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) là nền tảng AI inference đa phương thức toàn diện — một API và endpoint tương thích OpenAI (`https://api.atlascloud.ai/v1`) cho hơn 300 mô hình được tuyển chọn:

- **LLM** — DeepSeek, Qwen, Claude, GPT, Gemini, GLM, Kimi, MiniMax, Grok và nhiều hơn nữa
- **Ảnh** — FLUX, Seedream, gpt-image và nhiều hơn nữa
- **Video** — Seedance, Kling, Wan và nhiều hơn nữa
