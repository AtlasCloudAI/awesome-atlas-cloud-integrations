## AI Gateway & Router

- [axonhub](https://github.com/looplj/axonhub) — ओपन-सोर्स AI Gateway: किसी भी SDK के माध्यम से 100+ LLM को कॉल करें, जिसमें बिल्ट-इन failover, लोड बैलेंसिंग और ट्रेसिंग शामिल है।

## Agent फ्रेमवर्क और हार्नेस

- [oumi](https://github.com/oumi-ai/oumi) — Gemma, Qwen, gpt-oss, DeepSeek-R1 और अन्य ओपन LLM / VLM को fine-tune, मूल्यांकन और डिप्लॉय करें।
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — LangGraph के साथ AI agent सेवाएँ बनाने के लिए प्रोडक्शन-रेडी FastAPI टेम्पलेट।
- [octos](https://github.com/octos-org/octos) — Agentic ऑपरेटिंग सिस्टम।
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — लंबे समय तक चलने वाले, मल्टी-मॉडल, टूल-उपयोग करने वाले AI सिस्टम के लिए तेज़, उपयोग में आसान agent हार्नेस।
- [stash](https://github.com/alash3al/stash) — AI agent के लिए स्थायी मेमोरी लेयर, Postgres द्वारा समर्थित, बिल्ट-इन MCP server के साथ।

## Coding Agents

- [reopencode](https://github.com/MurrayHill1127/reopencode) — ओपन-सोर्स AI coding agent।
- [VTCode](https://github.com/vinhnx/VTCode) — LLM-native कोड समझ और मजबूत shell सुरक्षा वाला coding agent।
- [mathcode](https://github.com/math-ai-org/mathcode) — एक अग्रणी गणितीय coding agent।

## RAG & Data Pipelines

- [Verba](https://github.com/weaviate/Verba) — Weaviate द्वारा संचालित Retrieval-Augmented Generation (RAG) चैटबॉट।
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — एक Crawler जो वेबसाइटों को LLM-रेडी डेटा और संरचित SERP परिणामों में बदलता है।

## LLM Frameworks

- [LLPhant](https://github.com/LLPhant/LLPhant) — LangChain से प्रेरित, एक व्यापक PHP Generative AI फ्रेमवर्क।

## इमेज, वीडियो और मल्टीमॉडल

- [LightX2V](https://github.com/ModelTC/LightX2V) — हल्का इमेज / वीडियो जनरेशन inference फ्रेमवर्क।
- [paperbanana](https://github.com/llmsresearch/paperbanana) — स्वचालित अकादमिक आकृतियाँ, डायग्राम और शोध विज़ुअल।
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — विज़ुअल एडिटर और कई इंजनों वाला ओपन-सोर्स मंगा अनुवाद टूल।
- [opentalking](https://github.com/datascale-ai/opentalking) — रियल-टाइम वार्तालाप के साथ औद्योगिक-ग्रेड AI डिजिटल ह्यूमन फ्रेमवर्क।
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — OpenClaw या किसी भी MCP-समर्थित agent में उपयोग करने योग्य ड्रॉइंग MCP और skill।
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — आपका अपना निजी AIGC कारखाना, Comfy तरीके से।

## टेस्टिंग और सुरक्षा

- [gosec](https://github.com/securego/gosec) — Go सुरक्षा चेकर।

- [design-extract](https://github.com/Manavarya09/design-extract) — एक कमांड से किसी भी वेबसाइट का संपूर्ण design system निकालें।

## योगदान

योगदान का स्वागत है! Atlas Cloud (LLM / इमेज / वीडियो) को AI प्रदाता के रूप में एकीकृत करने वाले किसी ओपन-सोर्स प्रोजेक्ट को जोड़ने के लिए एक PR खोलें। फ़ॉर्मेट को सरल रखें:

```md
- [name](repo-url) — One-line description.
```

प्रविष्टि को सबसे प्रासंगिक श्रेणी के अंतर्गत जोड़ें। देखें [CONTRIBUTING.md](../CONTRIBUTING.md)।
