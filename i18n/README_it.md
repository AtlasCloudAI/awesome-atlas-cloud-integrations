## AI Gateway e Router

- [axonhub](https://github.com/looplj/axonhub) — AI Gateway open source: richiama oltre 100 LLM tramite qualsiasi SDK, con failover, bilanciamento del carico e tracing integrati.

## Framework e ambienti per agenti

- [oumi](https://github.com/oumi-ai/oumi) — Esegui fine-tuning, valuta e distribuisci Gemma, Qwen, gpt-oss, DeepSeek-R1 e altri LLM / VLM aperti.
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — Template FastAPI pronto per la produzione per creare servizi di agenti IA con LangGraph.
- [octos](https://github.com/octos-org/octos) — Sistema operativo agentico.
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — Ambiente per agenti veloce e facile da usare per sistemi IA a lungo orizzonte, multi-modello e che usano strumenti.
- [stash](https://github.com/alash3al/stash) — Livello di memoria persistente per agenti IA, basato su Postgres, con server MCP integrato.

## Agenti di programmazione

- [reopencode](https://github.com/MurrayHill1127/reopencode) — Agente di programmazione IA open source.
- [VTCode](https://github.com/vinhnx/VTCode) — Agente di programmazione con comprensione del codice nativa per LLM e robusta sicurezza della shell.
- [mathcode](https://github.com/math-ai-org/mathcode) — Un agente di programmazione matematica all'avanguardia.

## RAG e pipeline di dati

- [Verba](https://github.com/weaviate/Verba) — Chatbot di generazione aumentata dal recupero (RAG) basato su Weaviate.
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — Crawler che trasforma i siti web in dati pronti per LLM e risultati SERP strutturati.

## Framework per LLM

- [LLPhant](https://github.com/LLPhant/LLPhant) — Un framework PHP completo di IA generativa, ispirato a LangChain.

## Immagini, video e multimodale

- [LightX2V](https://github.com/ModelTC/LightX2V) — Framework di inferenza leggero per la generazione di immagini / video.
- [paperbanana](https://github.com/llmsresearch/paperbanana) — Figure accademiche, diagrammi e contenuti visivi di ricerca automatizzati.
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — Strumento di traduzione manga open source con editor visivo e più motori.
- [opentalking](https://github.com/datascale-ai/opentalking) — Framework di umano digitale IA di livello industriale con conversazione in tempo reale.
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — MCP e skill di disegno utilizzabili in OpenClaw o in qualsiasi agente compatibile con MCP.
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — La tua fabbrica personale di AIGC, in stile Comfy.

## Test e sicurezza

- [promptfoo](https://github.com/promptfoo/promptfoo) — Testa prompt, agenti e RAG; red teaming e scansione delle vulnerabilità per l'IA.
- [gosec](https://github.com/securego/gosec) — Verificatore di sicurezza per Go.

## Browser e strumenti web

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — Diagrammi interattivi gratuiti e veloci per qualsiasi repository GitHub.
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — Un'altra WebUI per Nginx.
- [page-assist](https://github.com/n4ze3m/page-assist) — Usa i tuoi modelli IA in esecuzione localmente per assisterti nella navigazione web.
- [design-extract](https://github.com/Manavarya09/design-extract) — Estrai il sistema di design completo di qualsiasi sito web con un solo comando.

## App desktop e companion

- [hermes-desktop](https://github.com/fathah/hermes-desktop) — App companion desktop per Hermes Agent.
- [fount](https://github.com/steve02081504/fount) — L'immaginazione a cui viene data voce: una piattaforma di personaggi / companion.

## Apprendimento e skill

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) — Converti siti di documentazione, repository GitHub e PDF in skill di Claude AI.
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) — Notebook per aiutarti a imparare l'IA da zero.

## Informazioni su Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) è una piattaforma di inferenza IA full-modale: un'unica API ed endpoint compatibili con OpenAI (`https://api.atlascloud.ai/v1`) per oltre 300 modelli curati:

- **LLM** — DeepSeek, Qwen, Claude, GPT, Gemini, GLM, Kimi, MiniMax, Grok e altri
- **Immagini** — FLUX, Seedream, gpt-image e altri
- **Video** — Seedance, Kling, Wan e altri
