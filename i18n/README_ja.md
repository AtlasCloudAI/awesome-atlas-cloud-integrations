## AI ゲートウェイ & ルーター

- [axonhub](https://github.com/looplj/axonhub) — オープンソースの AI ゲートウェイ。任意の SDK から 100+ の LLM を呼び出し、フェイルオーバー・負荷分散・トレーシングを内蔵。

## Agent フレームワーク & ハーネス

- [oumi](https://github.com/oumi-ai/oumi) — Gemma、Qwen、gpt-oss、DeepSeek-R1 などのオープン LLM / VLM をファインチューニング・評価・デプロイ。
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — LangGraph で AI agent サービスを構築するための本番対応 FastAPI テンプレート。
- [octos](https://github.com/octos-org/octos) — Agentic オペレーティングシステム。
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — 長期的・マルチモデル・ツール利用の AI システム向けの高速で使いやすい agent ハーネス。
- [stash](https://github.com/alash3al/stash) — AI agent 向けの永続メモリ層。Postgres を基盤とし、MCP サーバーを内蔵。

## コーディング Agent

- [reopencode](https://github.com/MurrayHill1127/reopencode) — オープンソースの AI コーディング agent。
- [VTCode](https://github.com/vinhnx/VTCode) — LLM ネイティブなコード理解と堅牢な shell セーフティを備えたコーディング agent。
- [mathcode](https://github.com/math-ai-org/mathcode) — 最先端の数学コーディング agent。

## RAG & データパイプライン

- [Verba](https://github.com/weaviate/Verba) — Weaviate を搭載した検索拡張生成（RAG）チャットボット。
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — ウェブサイトを LLM 対応データと構造化 SERP 結果に変換するクローラー。

## LLM フレームワーク

- [LLPhant](https://github.com/LLPhant/LLPhant) — LangChain に触発された包括的な PHP 生成 AI フレームワーク。

## 画像・動画・マルチモーダル

- [LightX2V](https://github.com/ModelTC/LightX2V) — 軽量な画像 / 動画生成推論フレームワーク。
- [paperbanana](https://github.com/llmsresearch/paperbanana) — 学術用の図・ダイアグラム・研究ビジュアルを自動生成。
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — ビジュアルエディタと複数エンジンを備えたオープンソースの漫画翻訳ツール。
- [opentalking](https://github.com/datascale-ai/opentalking) — リアルタイム会話に対応した産業グレードの AI デジタルヒューマンフレームワーク。
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — OpenClaw や MCP 対応の任意の agent で使える描画 MCP & skill。
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — あなた専用の AIGC ファクトリーを、Comfy 流で。

## テスト & セキュリティ

- [promptfoo](https://github.com/promptfoo/promptfoo) — プロンプト・agent・RAG をテスト。AI 向けのレッドチーミングと脆弱性スキャン。
- [gosec](https://github.com/securego/gosec) — Go セキュリティチェッカー。

## ブラウザ & Web ツール

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — 任意の GitHub リポジトリ向けの無料・高速なインタラクティブ図。
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — もう一つの Nginx 向け WebUI。
- [page-assist](https://github.com/n4ze3m/page-assist) — ローカルで動く AI モデルでウェブ閲覧を支援。
- [design-extract](https://github.com/Manavarya09/design-extract) — 任意のウェブサイトの完全なデザインシステムをワンコマンドで抽出。

## デスクトップ & コンパニオンアプリ

- [hermes-desktop](https://github.com/fathah/hermes-desktop) — Hermes Agent 向けのデスクトップコンパニオン。
- [fount](https://github.com/steve02081504/fount) — 想像に声を —— キャラクター / コンパニオンプラットフォーム。

## 学習 & スキル

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) — ドキュメントサイト・GitHub リポジトリ・PDF を Claude AI skill に変換。
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) — AI をゼロから学ぶための notebook。

## Atlas Cloud について

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) は全モーダルの AI 推論プラットフォームです —— 一つの OpenAI-compatible API とエンドポイント（`https://api.atlascloud.ai/v1`）で、厳選された 300+ のモデルを利用できます：

- **LLM** — DeepSeek、Qwen、Claude、GPT、Gemini、GLM、Kimi、MiniMax、Grok など
- **画像** — FLUX、Seedream、gpt-image など
- **動画** — Seedance、Kling、Wan など

[ウェブサイト](https://www.atlascloud.ai) · [ドキュメント](https://www.atlascloud.ai/docs) · [モデル](https://www.atlascloud.ai/models) · [Coding Plan](https://www.atlascloud.ai/console/coding-plan)
