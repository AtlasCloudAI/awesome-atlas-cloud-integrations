## AI 閘道與路由

- [axonhub](https://github.com/looplj/axonhub) — 開源 AI 閘道：透過任意 SDK 呼叫 100+ 個 LLM，內建故障轉移、負載平衡與鏈路追蹤。

## Agent 框架與執行環境

- [oumi](https://github.com/oumi-ai/oumi) — 微調、評估並部署 Gemma、Qwen、gpt-oss、DeepSeek-R1 等開源 LLM / VLM。
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — 以 LangGraph 建構 AI agent 服務的生產級 FastAPI 範本。
- [octos](https://github.com/octos-org/octos) — Agentic 作業系統。
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — 面向長程、多模型、可呼叫工具的 AI 系統的快速易用 agent 執行環境。
- [stash](https://github.com/alash3al/stash) — 面向 AI agent 的持久化記憶層，基於 Postgres，內建 MCP 伺服器。

## 程式設計 Agent

- [reopencode](https://github.com/MurrayHill1127/reopencode) — 開源 AI 程式設計 agent。
- [VTCode](https://github.com/vinhnx/VTCode) — 具備 LLM 原生程式碼理解能力與穩健 shell 安全機制的程式設計 agent。
- [mathcode](https://github.com/math-ai-org/mathcode) — 前沿的數學程式設計 agent。

## RAG 與資料管線

- [Verba](https://github.com/weaviate/Verba) — 基於 Weaviate 的檢索增強生成（RAG）聊天機器人。
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — 將網站轉化為 LLM 就緒資料與結構化 SERP 結果的爬蟲。

## LLM 框架

- [LLPhant](https://github.com/LLPhant/LLPhant) — 一個全面的 PHP 生成式 AI 框架，靈感來自 LangChain。

## 影像、影片與多模態

- [LightX2V](https://github.com/ModelTC/LightX2V) — 輕量級影像 / 影片生成推論框架。
- [paperbanana](https://github.com/llmsresearch/paperbanana) — 自動生成學術插圖、示意圖與科研視覺化。
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — 帶視覺化編輯器與多引擎的開源漫畫翻譯工具。
- [opentalking](https://github.com/datascale-ai/opentalking) — 工業級 AI 數位人框架，支援即時對話。
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — 可在 OpenClaw 或任意支援 MCP 的 agent 中使用的繪圖 MCP 與 skill。
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — 屬於你自己的私人 AIGC 工廠，Comfy 方式。

## 測試與安全

- [promptfoo](https://github.com/promptfoo/promptfoo) — 測試提示詞、agent 與 RAG；面向 AI 的紅隊演練與漏洞掃描。
- [gosec](https://github.com/securego/gosec) — Go 安全檢查工具。

## 瀏覽器與 Web 工具

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — 為任意 GitHub 儲存庫免費、快速生成互動式圖表。
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — 又一款 Nginx 的 WebUI。
- [page-assist](https://github.com/n4ze3m/page-assist) — 用本地執行的 AI 模型輔助你的網頁瀏覽。
- [design-extract](https://github.com/Manavarya09/design-extract) — 一條命令提取任意網站完整的設計系統。

## 桌面與陪伴應用

- [hermes-desktop](https://github.com/fathah/hermes-desktop) — Hermes Agent 的桌面伴侶應用。
- [fount](https://github.com/steve02081504/fount) — 讓想像發聲 —— 一個角色 / 陪伴平台。

## 學習與技能

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) — 將文件網站、GitHub 儲存庫與 PDF 轉換為 Claude AI skill。
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) — 幫助你從零開始學習 AI 的 notebook。

## 關於 Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) 是一個全模態 AI 推論平台 —— 一套 OpenAI-compatible API 與端點（`https://api.atlascloud.ai/v1`），精選 300+ 個模型：

- **LLM** — DeepSeek、Qwen、Claude、GPT、Gemini、GLM、Kimi、MiniMax、Grok 等
- **影像** — FLUX、Seedream、gpt-image 等
- **影片** — Seedance、Kling、Wan 等
