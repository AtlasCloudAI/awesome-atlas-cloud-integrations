## AI-шлюз и маршрутизатор

- [axonhub](https://github.com/looplj/axonhub) — AI-шлюз с открытым исходным кодом: вызывайте более 100 LLM через любой SDK со встроенными механизмами отказоустойчивости, балансировки нагрузки и трассировки.

## Фреймворки и платформы для агентов

- [oumi](https://github.com/oumi-ai/oumi) — Дообучение, оценка и развёртывание Gemma, Qwen, gpt-oss, DeepSeek-R1 и других открытых LLM / VLM.
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — Готовый к продакшену шаблон FastAPI для создания сервисов AI-агентов на LangGraph.
- [octos](https://github.com/octos-org/octos) — Агентная операционная система.
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — Быстрая и простая в использовании платформа для агентов, рассчитанная на долгосрочные многомодельные AI-системы с использованием инструментов.
- [stash](https://github.com/alash3al/stash) — Слой постоянной памяти для AI-агентов на базе Postgres со встроенным MCP-сервером.

## Кодинг-агенты

- [reopencode](https://github.com/MurrayHill1127/reopencode) — AI-агент для написания кода с открытым исходным кодом.
- [VTCode](https://github.com/vinhnx/VTCode) — Кодинг-агент с нативным для LLM пониманием кода и надёжной защитой при работе с shell.
- [mathcode](https://github.com/math-ai-org/mathcode) — Передовой агент для написания математического кода.

## RAG и конвейеры данных

- [Verba](https://github.com/weaviate/Verba) — Чат-бот с поиском с дополненной генерацией (RAG) на базе Weaviate.
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — Краулер, который превращает сайты в готовые для LLM данные и структурированные результаты SERP.

## LLM-фреймворки

- [LLPhant](https://github.com/LLPhant/LLPhant) — Полнофункциональный PHP-фреймворк для генеративного AI, вдохновлённый LangChain.

## Изображения, видео и мультимодальность

- [LightX2V](https://github.com/ModelTC/LightX2V) — Лёгкий фреймворк для инференса генерации изображений / видео.
- [paperbanana](https://github.com/llmsresearch/paperbanana) — Автоматическое создание академических иллюстраций, диаграмм и научной графики.
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — Инструмент перевода манги с открытым исходным кодом, визуальным редактором и несколькими движками.
- [opentalking](https://github.com/datascale-ai/opentalking) — Фреймворк промышленного уровня для AI-цифровых людей с диалогом в реальном времени.
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — MCP и навык для рисования, пригодные для OpenClaw или любого агента с поддержкой MCP.
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — Ваша личная фабрика AIGC по-комфаевски.

## Тестирование и безопасность

- [promptfoo](https://github.com/promptfoo/promptfoo) — Тестирование промптов, агентов и RAG; red teaming и сканирование уязвимостей для AI.
- [gosec](https://github.com/securego/gosec) — Проверка безопасности кода на Go.

## Браузерные и веб-инструменты

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — Бесплатные, быстрые интерактивные диаграммы для любого репозитория GitHub.
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — Ещё один WebUI для Nginx.
- [page-assist](https://github.com/n4ze3m/page-assist) — Используйте локально запущенные AI-модели в помощь при веб-сёрфинге.
- [design-extract](https://github.com/Manavarya09/design-extract) — Извлекайте полную дизайн-систему любого сайта одной командой.

## Десктопные и сопутствующие приложения

- [fount](https://github.com/steve02081504/fount) — Воображение, обретающее голос — платформа персонажей / компаньонов.

## Участие в проекте

Мы приветствуем ваш вклад! Откройте PR, чтобы добавить проект с открытым исходным кодом, который интегрирует Atlas Cloud (LLM / изображения / видео) в качестве AI-провайдера. Сохраняйте простой формат:

```md
- [name](repo-url) — Однострочное описание.
```

Добавляйте запись в наиболее подходящую категорию. См. [CONTRIBUTING.md](../CONTRIBUTING.md).

## Об Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) — это полномодальная платформа AI-инференса: единый OpenAI-compatible API и эндпоинт (`https://api.atlascloud.ai/v1`) для более чем 300 тщательно отобранных моделей:

- **LLM** — DeepSeek, Qwen, Claude, GPT, Gemini, GLM, Kimi, MiniMax, Grok и другие
- **Изображения** — FLUX, Seedream, gpt-image и другие
- **Видео** — Seedance, Kling, Wan и другие
