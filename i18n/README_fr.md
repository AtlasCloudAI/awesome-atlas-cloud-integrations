## AI Gateway et Router

- [axonhub](https://github.com/looplj/axonhub) — AI Gateway open source : appelez plus de 100 LLM via n'importe quel SDK, avec basculement, répartition de charge et traçage intégrés.

## Frameworks et environnements d'agents

- [oumi](https://github.com/oumi-ai/oumi) — Affinez, évaluez et déployez Gemma, Qwen, gpt-oss, DeepSeek-R1 et d'autres LLM / VLM ouverts.
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — Modèle FastAPI prêt pour la production pour créer des services d'agents IA avec LangGraph.
- [octos](https://github.com/octos-org/octos) — Système d'exploitation agentique.
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — Environnement d'agents rapide et facile à utiliser pour des systèmes d'IA à long horizon, multi-modèles et utilisant des outils.
- [stash](https://github.com/alash3al/stash) — Couche de mémoire persistante pour agents IA, reposant sur Postgres, avec un serveur MCP intégré.

## Agents de programmation

- [reopencode](https://github.com/MurrayHill1127/reopencode) — Agent de programmation IA open source.
- [VTCode](https://github.com/vinhnx/VTCode) — Agent de programmation avec compréhension du code native au LLM et sécurité shell robuste.
- [mathcode](https://github.com/math-ai-org/mathcode) — Un agent de programmation mathématique de pointe.

## RAG et pipelines de données

- [Verba](https://github.com/weaviate/Verba) — Chatbot de génération augmentée par récupération (RAG) propulsé par Weaviate.
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — Crawler qui transforme les sites web en données prêtes pour le LLM et en résultats SERP structurés.

## Frameworks de LLM

- [LLPhant](https://github.com/LLPhant/LLPhant) — Un framework PHP complet d'IA générative, inspiré de LangChain.

## Image, vidéo et multimodal

- [LightX2V](https://github.com/ModelTC/LightX2V) — Framework d'inférence léger pour la génération d'images / de vidéos.
- [paperbanana](https://github.com/llmsresearch/paperbanana) — Figures académiques, diagrammes et visuels de recherche automatisés.
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — Outil de traduction de manga open source avec éditeur visuel et plusieurs moteurs.
- [opentalking](https://github.com/datascale-ai/opentalking) — Framework d'humain numérique IA de niveau industriel avec conversation en temps réel.
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — MCP et skill de dessin utilisables dans OpenClaw ou tout agent compatible MCP.
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — Votre propre usine personnelle d'AIGC, façon Comfy.

## Tests et sécurité

- [promptfoo](https://github.com/promptfoo/promptfoo) — Testez prompts, agents et RAG ; red teaming et analyse de vulnérabilités pour l'IA.
- [gosec](https://github.com/securego/gosec) — Vérificateur de sécurité pour Go.

## Navigateur et outils web

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — Diagrammes interactifs gratuits et rapides pour n'importe quel dépôt GitHub.
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — Encore une WebUI pour Nginx.
- [page-assist](https://github.com/n4ze3m/page-assist) — Utilisez vos modèles d'IA exécutés localement pour vous assister dans votre navigation web.
- [design-extract](https://github.com/Manavarya09/design-extract) — Extrayez le système de design complet de n'importe quel site web avec une seule commande.

## Applications de bureau et de compagnie

- [hermes-desktop](https://github.com/fathah/hermes-desktop) — Application de compagnie de bureau pour Hermes Agent.
- [fount](https://github.com/steve02081504/fount) — L'imagination, dotée d'une voix : une plateforme de personnages / de compagnie.

## Apprentissage et skills

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) — Convertissez des sites de documentation, des dépôts GitHub et des PDF en skills Claude AI.
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) — Notebooks pour vous aider à apprendre l'IA à partir de zéro.

## Contributing

Les contributions sont les bienvenues ! Ouvrez une PR pour ajouter un projet open source qui intègre Atlas Cloud (LLM / image / vidéo) comme fournisseur d'IA. Gardez un format simple :

```md
- [name](repo-url) — One-line description.
```

Ajoutez l'entrée dans la catégorie la plus pertinente. Voir [CONTRIBUTING.md](../CONTRIBUTING.md).

## À propos d'Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) est une plateforme d'inférence IA full-modale : une seule API et un seul endpoint compatibles OpenAI (`https://api.atlascloud.ai/v1`) pour plus de 300 modèles sélectionnés :

- **LLM** — DeepSeek, Qwen, Claude, GPT, Gemini, GLM, Kimi, MiniMax, Grok et plus
- **Image** — FLUX, Seedream, gpt-image et plus
- **Vidéo** — Seedance, Kling, Wan et plus
