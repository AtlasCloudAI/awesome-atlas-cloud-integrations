## بوابة وموجِّه الذكاء الاصطناعي

- [axonhub](https://github.com/looplj/axonhub) — بوابة ذكاء اصطناعي مفتوحة المصدر: استدعِ أكثر من 100 نموذج LLM عبر أي SDK، مع آليات مدمجة للتجاوز عند الفشل وموازنة الأحمال والتتبع.

## أُطر ومنصّات الوكلاء

- [oumi](https://github.com/oumi-ai/oumi) — ضبط دقيق وتقييم ونشر لنماذج Gemma وQwen وgpt-oss وDeepSeek-R1 وغيرها من نماذج LLM / VLM المفتوحة.
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — قالب FastAPI جاهز للإنتاج لبناء خدمات وكلاء الذكاء الاصطناعي باستخدام LangGraph.
- [octos](https://github.com/octos-org/octos) — نظام تشغيل قائم على الوكلاء.
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — منصّة وكلاء سريعة وسهلة الاستخدام لأنظمة الذكاء الاصطناعي طويلة الأمد ومتعددة النماذج والمستخدِمة للأدوات.
- [stash](https://github.com/alash3al/stash) — طبقة ذاكرة دائمة لوكلاء الذكاء الاصطناعي، مدعومة بـ Postgres، مع خادم MCP مدمج.

## وكلاء البرمجة

- [reopencode](https://github.com/MurrayHill1127/reopencode) — وكيل برمجة بالذكاء الاصطناعي مفتوح المصدر.
- [VTCode](https://github.com/vinhnx/VTCode) — وكيل برمجة بفهم للكود أصيل في نماذج LLM وأمان قوي عند التعامل مع shell.
- [mathcode](https://github.com/math-ai-org/mathcode) — وكيل برمجة رياضي متطوّر.

## RAG وخطوط معالجة البيانات

- [Verba](https://github.com/weaviate/Verba) — روبوت محادثة بتقنية التوليد المعزَّز بالاسترجاع (RAG) مدعوم بـ Weaviate.
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — زاحف يحوّل المواقع إلى بيانات جاهزة لنماذج LLM ونتائج SERP منظَّمة.

## أُطر LLM

- [LLPhant](https://github.com/LLPhant/LLPhant) — إطار عمل شامل للذكاء الاصطناعي التوليدي بلغة PHP، مستوحى من LangChain.

## الصور والفيديو ومتعدد الوسائط

- [LightX2V](https://github.com/ModelTC/LightX2V) — إطار خفيف للاستدلال في توليد الصور / الفيديو.
- [paperbanana](https://github.com/llmsresearch/paperbanana) — توليد آلي للأشكال الأكاديمية والمخططات والمرئيات البحثية.
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — أداة ترجمة مانغا مفتوحة المصدر مع محرّر مرئي ومحرّكات متعددة.
- [opentalking](https://github.com/datascale-ai/opentalking) — إطار للبشر الرقميين بالذكاء الاصطناعي بمستوى صناعي مع محادثة في الوقت الفعلي.
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — MCP ومهارة للرسم قابلة للاستخدام في OpenClaw أو أي وكيل يدعم MCP.
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — مصنع AIGC الشخصي الخاص بك، على طريقة Comfy.

## الاختبار والأمان

- [promptfoo](https://github.com/promptfoo/promptfoo) — اختبار المطالبات والوكلاء وأنظمة RAG؛ مع red teaming وفحص الثغرات للذكاء الاصطناعي.
- [gosec](https://github.com/securego/gosec) — مدقّق أمان للغة Go.

## أدوات المتصفّح والويب

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — مخططات تفاعلية مجانية وسريعة لأي مستودع على GitHub.
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — واجهة WebUI أخرى لـ Nginx.
- [page-assist](https://github.com/n4ze3m/page-assist) — استخدم نماذج الذكاء الاصطناعي العاملة محليًا لمساعدتك في تصفّح الويب.
- [design-extract](https://github.com/Manavarya09/design-extract) — استخرج نظام التصميم الكامل لأي موقع بأمر واحد.

## تطبيقات سطح المكتب والتطبيقات المرافِقة

- [hermes-desktop](https://github.com/fathah/hermes-desktop) — تطبيق مرافِق لسطح المكتب لـ Hermes Agent.
- [fount](https://github.com/steve02081504/fount) — الخيال يُمنح صوتًا — منصّة شخصيات / رفقاء.

## التعلّم والمهارات

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) — حوّل مواقع التوثيق ومستودعات GitHub وملفات PDF إلى مهارات Claude AI.
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) — دفاتر ملاحظات تساعدك على تعلّم الذكاء الاصطناعي من الصفر.

## عن Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) هي منصّة استدلال ذكاء اصطناعي متعددة الوسائط بالكامل — واجهة API ونقطة نهاية واحدة متوافقة مع OpenAI (`https://api.atlascloud.ai/v1`) لأكثر من 300 نموذج مُنتقى:

- **نماذج LLM** — DeepSeek وQwen وClaude وGPT وGemini وGLM وKimi وMiniMax وGrok وغيرها
- **الصور** — FLUX وSeedream وgpt-image وغيرها
- **الفيديو** — Seedance وKling وWan وغيرها
