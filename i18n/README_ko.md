## AI 게이트웨이 & 라우터

- [axonhub](https://github.com/looplj/axonhub) — 오픈소스 AI 게이트웨이. 어떤 SDK로든 100개 이상의 LLM을 호출하며, 페일오버, 로드 밸런싱, 트레이싱을 기본 제공.

## Agent 프레임워크 & 하네스

- [oumi](https://github.com/oumi-ai/oumi) — Gemma, Qwen, gpt-oss, DeepSeek-R1 등 오픈 LLM / VLM을 파인튜닝, 평가, 배포.
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) — LangGraph로 AI agent 서비스를 구축하기 위한 프로덕션 준비된 FastAPI 템플릿.
- [octos](https://github.com/octos-org/octos) — Agentic 운영 체제.
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) — 장기 호라이즌, 멀티 모델, 도구 사용 AI 시스템을 위한 빠르고 사용하기 쉬운 agent 하네스.
- [stash](https://github.com/alash3al/stash) — AI agent를 위한 영속 메모리 계층. Postgres 기반이며 MCP 서버 내장.

## 코딩 Agent

- [reopencode](https://github.com/MurrayHill1127/reopencode) — 오픈소스 AI 코딩 agent.
- [VTCode](https://github.com/vinhnx/VTCode) — LLM 네이티브 코드 이해와 견고한 shell 안전성을 갖춘 코딩 agent.
- [mathcode](https://github.com/math-ai-org/mathcode) — 최첨단 수학 코딩 agent.

## RAG & 데이터 파이프라인

- [Verba](https://github.com/weaviate/Verba) — Weaviate 기반의 검색 증강 생성(RAG) 챗봇.
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) — 웹사이트를 LLM 준비 데이터와 구조화된 SERP 결과로 변환하는 크롤러.

## LLM 프레임워크

- [LLPhant](https://github.com/LLPhant/LLPhant) — LangChain에서 영감을 받은 종합적인 PHP 생성형 AI 프레임워크.

## 이미지, 비디오 & 멀티모달

- [LightX2V](https://github.com/ModelTC/LightX2V) — 경량 이미지 / 비디오 생성 추론 프레임워크.
- [paperbanana](https://github.com/llmsresearch/paperbanana) — 학술용 그림, 다이어그램, 연구 비주얼을 자동 생성.
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) — 비주얼 에디터와 여러 엔진을 갖춘 오픈소스 만화 번역 도구.
- [opentalking](https://github.com/datascale-ai/opentalking) — 실시간 대화를 지원하는 산업용 AI 디지털 휴먼 프레임워크.
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) — OpenClaw나 MCP를 지원하는 모든 agent에서 사용 가능한 드로잉 MCP & skill.
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) — 당신만의 개인 AIGC 공장, Comfy 방식으로.

## 테스트 & 보안

- [promptfoo](https://github.com/promptfoo/promptfoo) — 프롬프트, agent, RAG를 테스트. AI를 위한 레드 팀 및 취약점 스캐닝.
- [gosec](https://github.com/securego/gosec) — Go 보안 검사기.

## 브라우저 & 웹 도구

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) — 모든 GitHub 저장소를 위한 무료, 빠른 인터랙티브 다이어그램.
- [nginx-ui](https://github.com/0xJacky/nginx-ui) — 또 하나의 Nginx WebUI.
- [page-assist](https://github.com/n4ze3m/page-assist) — 로컬에서 실행되는 AI 모델로 웹 브라우징을 지원.
- [design-extract](https://github.com/Manavarya09/design-extract) — 한 번의 명령으로 모든 웹사이트의 완전한 디자인 시스템을 추출.

## 데스크톱 & 컴패니언 앱

- [hermes-desktop](https://github.com/fathah/hermes-desktop) — Hermes Agent를 위한 데스크톱 컴패니언.
- [fount](https://github.com/steve02081504/fount) — 상상에 목소리를 —— 캐릭터 / 컴패니언 플랫폼.

## 학습 & 스킬

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) — 문서 사이트, GitHub 저장소, PDF를 Claude AI skill로 변환.
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) — AI를 처음부터 배우는 데 도움이 되는 notebook.

## Atlas Cloud 소개

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations)는 풀 모달 AI 추론 플랫폼입니다 —— 하나의 OpenAI-compatible API와 엔드포인트(`https://api.atlascloud.ai/v1`)로 엄선된 300개 이상의 모델을 제공합니다:

- **LLM** — DeepSeek, Qwen, Claude, GPT, Gemini, GLM, Kimi, MiniMax, Grok 등
- **이미지** — FLUX, Seedream, gpt-image 등
- **비디오** — Seedance, Kling, Wan 등
