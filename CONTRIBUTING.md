# Contributing to Awesome Atlas Cloud

Thanks for helping grow this list of open-source projects integrated with [Atlas Cloud](https://www.atlascloud.ai/)!

## Adding a project

1. The project should have a **merged PR** (or shipped release) integrating Atlas Cloud as an AI provider — LLM (OpenAI-compatible `https://api.atlascloud.ai/v1`), image, or video generation.
2. Add **one entry** under the most relevant category in `README.md`, using this format:
   ```md
   - **[name](repo-url)** ⭐stars `Language` — One-line description. ([Integration PR](pr-url))
   ```
3. Sort entries by **star count (descending)** within each category.
4. If no category fits, propose a new one in your PR.

## Guidelines

- One line per project; keep descriptions factual and concise (prefer the project's own description).
- Always link the **integration PR** so others can see how it was done.
- No duplicates, no broken links.
- Star counts use `k` for thousands (e.g. `⭐1.6k`); language in backticks.

That's it — open your PR! 🙌
