## AI 网关与路由

- [axonhub](https://github.com/looplj/axonhub) —— 开源 AI 网关：用任意 SDK 调用 100+ 个 LLM，内置故障转移、负载均衡与全链路追踪。

## 智能体框架与 Harness

- [oumi](https://github.com/oumi-ai/oumi) —— 轻松微调、评估和部署 Gemma、Qwen、gpt-oss、DeepSeek-R1 等开源 LLM / VLM。
- [fastapi-langgraph-agent-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template) —— 基于 LangGraph 的生产级 FastAPI 模板，用于构建 AI 智能体服务。
- [octos](https://github.com/octos-org/octos) —— 智能体操作系统（Agentic OS）。
- [cheetahclaws](https://github.com/SafeRL-Lab/cheetahclaws) —— 面向长程、多模型、工具调用 AI 系统的高效易用智能体 Harness。
- [stash](https://github.com/alash3al/stash) —— AI 智能体的持久记忆层，基于 Postgres，内置 MCP server。

## 编程智能体

- [reopencode](https://github.com/MurrayHill1127/reopencode) —— 开源 AI 编程智能体。
- [VTCode](https://github.com/vinhnx/VTCode) —— 具备 LLM 原生代码理解和稳健 shell 安全的编程智能体。
- [mathcode](https://github.com/math-ai-org/mathcode) —— 前沿数学编程智能体。

## RAG 与数据管线

- [Verba](https://github.com/weaviate/Verba) —— 由 Weaviate 驱动的检索增强生成（RAG）聊天机器人。
- [AnyCrawl](https://github.com/any4ai/AnyCrawl) —— 将网站转为 LLM 就绪数据、并提取结构化 SERP 结果的爬虫。

## LLM 框架

- [LLPhant](https://github.com/LLPhant/LLPhant) —— 受 LangChain 启发的全功能 PHP 生成式 AI 框架。

## 图像、视频与多模态

- [LightX2V](https://github.com/ModelTC/LightX2V) —— 轻量级图像 / 视频生成推理框架。
- [paperbanana](https://github.com/llmsresearch/paperbanana) —— 自动生成学术图表、示意图与研究可视化。
- [manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui) —— 开源漫画翻译工具，含可视化编辑器与多种翻译引擎。
- [opentalking](https://github.com/datascale-ai/opentalking) —— 工业级开源 AI 数字人框架，支持实时对话。
- [gemini-skill](https://github.com/WJZ-P/gemini-skill) —— 可在 OpenClaw 或任意支持 MCP 的智能体中使用的绘图 MCP & skill。
- [ComfyUI-OpenClaw](https://github.com/rookiestar28/ComfyUI-OpenClaw) —— 你的私人 AIGC 工厂，用 Comfy 的方式打造。

## 测试与安全

- [promptfoo](https://github.com/promptfoo/promptfoo) —— 测试 prompt、智能体和 RAG；面向 AI 的红队与漏洞扫描。
- [gosec](https://github.com/securego/gosec) —— Go 安全检查器。

## 浏览器与 Web 工具

- [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram) —— 为任意 GitHub 仓库生成免费、快速的交互式架构图。
- [nginx-ui](https://github.com/0xJacky/nginx-ui) —— 又一个 Nginx WebUI。
- [page-assist](https://github.com/n4ze3m/page-assist) —— 用本地运行的 AI 模型辅助网页浏览。
- [design-extract](https://github.com/Manavarya09/design-extract) —— 一条命令提取任意网站的完整设计系统。

## 桌面与陪伴应用

- [hermes-desktop](https://github.com/fathah/hermes-desktop) —— Hermes Agent 的桌面陪伴端。
- [fount](https://github.com/steve02081504/fount) —— 让想象发声 —— 角色 / 陪伴平台。

## 学习与技能

- [Skill_Seekers](https://github.com/yusufkaraaslan/Skill_Seekers) —— 将文档站、GitHub 仓库和 PDF 转为 Claude AI skills。
- [ai-hands-on](https://github.com/Ramakm/ai-hands-on) —— 从零学习 AI 的 notebook 合集。

## 关于 Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlas-cloud-integrations) 是一个全模态 AI 推理平台 —— 一个 OpenAI 兼容 API 和端点（`https://api.atlascloud.ai/v1`），接入 300+ 个精选模型：

- **大语言模型** —— DeepSeek、Qwen、Claude、GPT、Gemini、GLM、Kimi、MiniMax、Grok 等
- **图像生成** —— FLUX、Seedream、gpt-image 等
- **视频生成** —— Seedance、Kling、Wan 等
