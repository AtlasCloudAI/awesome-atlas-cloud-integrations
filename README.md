## Contributing

Contributions are welcome! This list tracks open-source projects that integrate Atlas Cloud.

To add a project:

1. Make sure the project has a **merged** PR or released integration that adds Atlas Cloud as an AI provider (LLM / image / video).
2. Open a PR adding an entry under the most relevant category, keeping the format:
   ```md
   - **[name](repo-url)** ⭐stars `Language` — One-line description. ([Integration PR](pr-url))
   ```
3. Keep entries sorted by stars within each category.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for details.

## About Atlas Cloud

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=awesome-atlascloud) is a full-modal AI inference platform that gives developers a single, OpenAI-compatible API for:

- **LLMs** — DeepSeek, Qwen, Claude, GPT, Gemini, GLM, Kimi, MiniMax, Grok and more
- **Image generation** — FLUX, Seedream, gpt-image and more
- **Video generation** — Seedance, Kling, Wan and more

One API key, one endpoint (`https://api.atlascloud.ai/v1`), 300+ curated models.
